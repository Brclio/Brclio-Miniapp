# 内置头像第二版：1000 个独立原创图像

版本：20261026。生成方式：内置 `image_gen`，每个 ID 独立调用一次，输出一张完整头像。此文件和 `prompts.json` 是创意生产清单，不代表图像已经生成或通过验收。

## 创意方向

以开放、多样的角色与视觉故事替代上一版相似动物脸模板。人物、植物、器物、建筑、风景、抽象雕塑、科技伙伴与奇幻生物共同组成收藏。猫狗只占一个主题；其余主题中出现的动物必须有清楚的物种结构与独立姿态。禁止老鼠、大鼠及其他啮齿动物，不以改颜色、换配件作为不同头像。

每个主题有 10 个不同核心原型，每个原型安排 5 个不同的行动或场景，共 50 个独立叙事构图。相同原型的五张图必须改变动作、构图、互动对象和视觉故事；不能制作同一张脸的简单变体。每张 prompt 已写明主体、行为、材质、配色及头像裁切要求。

## 材质与艺术表现

十种表现方式在收藏中交错出现：陶瓷与毛毡、层叠纸雕、手绘水粉、温润木雕、编辑插画、收藏玩具、黏土微景、像素艺术、彩色玻璃、蜡笔与拼贴。不同主题和场景选择不同媒介，整体以精细手作质感、清楚的大轮廓和温暖鲜明的色彩维系品质。像素艺术采用清晰像素块；人物肖像保留年龄、肤色、发型与面部结构差异；抽象艺术以空间张力与材质表达故事。

色彩覆盖珊瑚、陶土、森林绿、金盏黄、深梅紫、覆盆子、橄榄、铜与暖奶油等组合，不统一套用蓝底或同一肤色。每张图选与主体对比清楚的安静背景。

## 图像与构图约束

- 每次只生成一个独立头像；禁止拼版、联系表、atlas 或把一张图切成多个头像。
- 正方形 1:1；保留内置工具的原始输出作为制作原件，最终展示导出 256×256 PNG。
- 头像在 48×48 像素仍应能识别。主体与关键特征完整处于画面中央 75%，可安全圆形裁切。
- 一张图只设一个视觉中心；双人/双物概念必须组成一个紧密整体。辅助道具最多两个。
- 不出现文字、字母、编号、数字、品牌、logo、水印、边框或假界面。
- 不使用通用圆头动物脸；猫、狗、鸟、海洋动物等按各自结构设计，不混入鼠耳、鼠鼻或鼠类轮廓。
- 不用简单重绘、换色或换饰品充数；避免拥挤场景、过多细节、廉价霓虹渐变和通用素材感。

## 逐张验收

检查原图及 48 像素缩略图：主题与 prompt 相符、没有鼠类结构、主要轮廓与同页其他头像有明显差异、构图经得起圆形裁切、背景与主体对比清楚、没有乱码或水印。失败图仅重做对应 ID，不以一张联系表替代若干独立输出。

制作过程应记录每张图的生成结果、原始文件、展示文件和验收状态；在 1000 张均已完成之前如实报告完成数量。

## Prompt 清单格式

`prompts.json` 为唯一编号来源：`schemaVersion: 2`、`version: "20261026"`、`mode: "builtin-imagegen"`；`themes` 含 20 个中文主题，`avatars` 含 1000 条 `{id,title,theme,themeIndex,prompt}`。所有标题和 prompt 唯一。
