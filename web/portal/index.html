隐私与服务说明 ＋

摄影图册、双人反应挑战与词了个词无需登录。网页与原生小程序均可作为访客使用，也可注册或登录同一个账号。支持邮箱验证码、邮箱密码与账号密码登录；微信用户可先在小程序绑定邮箱，再使用同一邮箱或账号登录网页。当前不提供预约、交易或评论；登录后可主动上传自定义头像。FirstSight 沿用原相册图片，内容来自 FirstSight_Online 的 8 组婚纱与 1 组孕期实际摄影。

词了个词根据你选择的学习阶段、页面与单词，按需读取本站的词库和现有插图，不会在使用中调用图片生成服务。收藏、学习进度与通关足迹先保存在当前设备，支持导出通关 CSV。登录后自动同步学习进度、收藏、使用偏好和最近 200 条通关记录；设备上的完整通关历史继续保留。首次登录会一次接续本机访客记录，此后不同账号分别保存，退出登录回到访客记录。朗读使用浏览器提供的语音能力，可用性取决于设备与浏览器。

新账号从 1000 个内置头像中随机获得一个头像，已有账号首次登录时补齐；你可以随时切换。上传自定义头像时，仅处理你选择的一张图片（最大 10 MB），原始文件与压缩展示图分别存入私有 GitHub 账号仓库。展示图居中裁成 256×256 像素并压缩为 JPEG，GIF 仅展示静态画面。头像展示链接可被持有链接的人访问，原图不提供公开访问接口。更换头像不会删除已保存的原图及 Git 历史；如需删除，请联系开发者核实处理。

本站不接入广告。ReadyGoDuel 保留原作 PV 计数脚本，会向 counter.bornforthis.cn 发起请求。反应挑战的设置与最近 20 场战绩保存在本机，可在挑战中清除；清理微信缓存或浏览器存储可能一并删除学习记录和使用偏好。登录用户的可同步业务记录保存在独立的业务数据仓库，账号资料与会话保存在独立的账号数据仓库，每个用户分别保存。自定义彩头、彩头密码、导出文件与下载资源不会进入自动同步。账号会保持登录，主动退出会立即结束本机登录；离线时会在联网后继续撤销对应会话。网页、词库和图片由 Cloudflare 分发，服务方可能处理完成网络服务所需的 IP 地址、请求时间与浏览器等信息。
