# 0.1.8 原生头像布局修复

日期：2026-10-27（Asia/Shanghai）。用户要求完成代码提交 GitHub 与微信开发版上传，提交审核由用户负责。

## 版本描述

全新升级 1000 款创意头像，涵盖人物、萌宠、海洋、自然、太空与艺术等 20 个主题。支持随机分配、自由切换和自定义上传。修复小屏头像网格溢出、选中边框过宽及关闭按钮布局，原图与压缩头像分别保存。

## 修复内容

0.1.7 的素材、API 和静态检查通过后，补充的微信开发工具原生界面验收发现按钮默认宽度导致头像选择器溢出：第五列超出页面、选中项边框跨列、关闭按钮占位过大。

本次只在头像选择器内重置原生按钮宽度和边距，明确网格项占满各自轨道，关闭按钮使用 44px 触控区域，并允许标题区域合理伸缩。保留 1000 张图片、编号、提示词、缓存版本、自定义上传及私有 GitHub 存储逻辑。
