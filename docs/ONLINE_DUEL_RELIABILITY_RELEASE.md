# 在线 PK 保活与双端音频 · 0.1.12

日期：2026-10-28（Asia/Shanghai）。用户反馈偶尔掉线、曾有一台手机未播放开始音，后确认两边已有声音并要求继续核实；要求有人进入广场就持续保活，最后一人离开后静默。

## 已修复的问题

- 校准依赖上一条 pong 才继续探测，同时 `syncing` 阻止心跳：丢失第一条校准回复后，连接会再无心跳直到超时。改为独立的大厅 5 秒／对局 1 秒保活，普通状态更新不能延期心跳。
- 旧版从大厅 10 秒心跳切到对局 3 秒失联阈值，可能把先准备者几秒前的正常心跳立即判为过期。现在线租期独立为 60 秒，活动对局有新的检测起点；连续 4.5 秒失联只中止本轮，保留广场连接，避免误掉线和不公平结算。
- 临时断线自动使用新票据重连，间隔按 1／2／4／8／10 秒封顶；网络恢复立即尝试。离开、切后台、销毁或账号变化后取消任务。同账号异地进入、域名／证书／403 配置错误不会无限争抢连接。
- 两台手机分别预热本机打包的开始音和 GO，并等待原生播放确认后才发送准备。预热全程音量 0，实际信号到来才开启音量；播放故障／系统音频中断会中止本轮。在线声音设置独立于原同屏游戏，默认开启，保留明确的在线静音；在线页面退出时恢复应用原有静音开关策略。
