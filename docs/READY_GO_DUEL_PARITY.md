## 入口与扩展边界

| 入口 | 当前范围 |
| --- | --- |
| `/projects/ready-go-duel/` | 原版 React 网页视觉，触摸／无限模式 |

默认玩法按单轮先响应决胜，抢跑则对方获胜，没有 5 秒超时或平局窗口。1／3／5 分赛制、35 ms 平局窗口、5 秒超时、暂停和最近 20 场记录属于另选计分扩展。账号手动备份只处理计分扩展数据，不含密码保护彩头或临时战报。
