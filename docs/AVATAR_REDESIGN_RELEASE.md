# 全新创意头像库 0.1.7

设计启动：2026-10-26；发布核查：2026-10-27（Asia/Shanghai）。用户要求全部重新设计 1000 个内置头像，并指定使用 imagegen，开放创新与多样性优先。

## 设计与来源

- 使用内置 `image_gen` 逐张生成 1000 张独立位图，未使用 CLI/API fallback、程序绘画或图集切分。20 个主题各 50 张，每页 40 张交错呈现全部主题。
- 完整提示词及标题见 [prompts.json](../design/builtin-avatars-v2/prompts.json)，原始文件与逐次真实生成记录保存于本地 `artifacts/avatar-redesign/raw/`、`generation.json`。展示素材通过严格导入器核对原图和提示词 SHA256 后生成；原图保持不变。
- 展示图仅做 256×256 技术缩小与无损 PNG 编码，保留完整 RGB/RGBA 色彩与绘制细节。素材库远程按需加载，不进入小程序包；保留原有 1–1000 编号及用户选择，新增 `?v=20261026` 避免旧头像缓存。自定义头像上传及私有 GitHub 存储不变。
- 旧程序绘画脚本已停用，原命令改为只接收真实 imagegen 输出及完整来源记录的导入器，防止重新生成旧模板图。

## 本地验收

- 1000 张原图与展示图各自 SHA256 唯一；已逐张查看技术缩略图及 56px 圆形裁切。5 张因轮廓、裁切或近似构图问题重新生成，复查通过。
- 1000 张 256×256 PNG 合计 119,566,015 字节，所有旧头像均被替换；小程序只包含精简名称表，图片远程按需加载。
- `npm test`：513/513 通过；`npm run build`、`npm run check:release` 通过。
