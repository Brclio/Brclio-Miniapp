## 本版内容

首页新增育儿栏目和原生儿歌播放器，包含 47 首实际存在的音频、场景筛选、搜索、收藏、进度拖动、三种播放模式和前台定时停止。每首歌独立调用内置 `image_gen` 生成插画，完整提示词与逐图 SHA256 见 [封面清单](../design/nursery-covers/manifest.json)。

47 张封面统一为 256×256 渐进式 JPEG，共 **570,808 字节（557.4 KiB）**，单张 6,718–17,167 字节。1254×1254 原图本地归档，不进入 Git 或微信代码包。播放器与封面位于 `nursery` 分包；旧 `/pages/parenting/index` 分享入口按白名单转接。系统播放器使用 `pocket.bornforthis.cn/assets/nursery-covers/` 的同字节图片。原 MP3 仍使用用户指定的现有域名，没有新增存储服务。
