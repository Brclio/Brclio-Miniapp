- 原生独立在线 PK：随机红蓝、各自按钮、统一未来时间触发、反应结算、抢跑／平局／超时与异常中止；原同屏、无限、计分、彩头、战报保留。

- 免费额度优先：按需连接、WebSocket 休眠、空大厅删除 alarm，无 Cron／常驻后台轮询；邀请码惰性过期清理，心跳不逐次写入数据库或重复延期 alarm。本轮未请求升级付费计划。
