# 网页账号与跨端同步

2026-10-22，补全 `0.1.3` 独立网页的账号入口和模块存储。此前原生 `0.1.3` 开发包上传记录见 [ACCOUNT_SYNC_RELEASE.md](ACCOUNT_SYNC_RELEASE.md)。本轮为网页补全，使用同一账号后端与同步协议。

## 使用与存储

- 门户「我的」及右上角账号入口支持邮箱、账号、密码、邮箱验证码注册；支持邮箱验证码、邮箱密码、账号密码登录、退出、同步状态及手动同步。显示服务错误和验证码倒计时，提交期间避免重复请求，离页清除表单中的临时凭据。
- 网页与原生复用账号客户端和同步控制器；会话无固定期限，主动退出清除本机会话并撤销当前服务端会话，离线撤销持久排队。微信创建的账号先在小程序绑定邮箱，即可使用同一邮箱或账号进入网页。
- ReadyGo 原版、计分扩展及 LingoTiles 接入同一账号存储。自定义彩头及彩头密码仅在本机按账号隔离，资源缓存和导出文件不上传；LingoTiles 完整通关历史继续存入本机 IndexedDB，云端保存最近 200 条，完整历史仍可导出 CSV。
- 仅首个登录账号接续旧访客数据。跨标签页换号、退出或缓存页面恢复时核对身份，冻结旧模块并重新加载，避免内存中的旧游戏向其他账号写入。读取损坏的本机值不会以默认值覆盖原数据。
- 模块在启动前最多等待 1.8 秒恢复账号数据，超时后使用本机记录继续；游戏启动后仅在后台上传，迟到响应不会改写正在使用的设置或局面。门户账号页可安全拉取，断网操作先存本机，联网后重试。
- 账号、凭据、会话、验证码只存 `BrclioData/Brclio-Miniapp-UserData`；同步业务只存 `BrclioData/Brclio-Miniapp-Data`，每位用户独立分片目录。没有新建存储服务、数据库或第三方账号系统。

## 构建与验证

网页构建将账号运行时放在所有公开模块的应用脚本之前，并加载独立作用域的账号浮层样式。ReadyGo 与 LingoTiles 继续从固定来源通过明确适配生成，原始来源文件不修改；学习规则、IDB 验证与 CSV 实现保留来源契约。注册与登录只发送至当前 HTTPS origin 的固定 `/api/account/*` 路径，本地 HTTP 预览继续以访客身份运行。

测试覆盖真实门户 DOM 事件、共享客户端集成、持久会话、账号隔离、错误存储、断网、浏览器缓存恢复、游戏启动与迟到响应、原版 React 组件、历史聚合及来源字节契约。完整 `npm run build` 成功，原生 `miniprogram/` 字节未变化；全量 `npm test` 421/421 通过，无失败或跳过；`npm run check:release` 93 项通过，`git diff --check` 通过。3,852 个源码与产物文件扫描真实凭据值，匹配 0，环境文件未跟踪。

首次生产联调发现退出请求较慢时可能清空新登录表单，已改为立即完成本机退出，之后的后台撤销响应不再修改新输入、验证码或隐私勾选，并新增完整回归用例。该次 QA 当前文件已按归属校验清理，随后使用新的独立 QA 复测。

浏览器实际检查本地构建的桌面与 390×844 手机表单、ReadyGo 及学习模块账号入口；学习页浮层已避开手机底部导航。部署后正式页面的浏览器控制持续超时，未取得新的线上交互截图，不将 HTTP 校验冒充正式浏览器点击验收。
