# 在线 PK 双方彩头 · 0.1.13

日期：2026-10-28（Asia/Shanghai）。用户要求 PK 模式双方都能随机或指定彩头，延续此前完成后核查、上线的授权。

## 功能与约定

- 双方分别设置自己赢了想要的彩头；指定文字最多 80 个 Unicode 字符，或复用原彩头库按分类随机抽取，也可留空、清空。修改权限限本人，两边显示服务端确认的内容。
- 彩头修改撤销双方准备。准备绑定房间与约定版本，音频预热、时钟校准和网络传输期间的旧确认不会误开局。保存有请求回执；未保存、待确认或失败时不能悄悄开局。
- 开局冻结本轮内容，结果展示赢家自己对应的彩头；平局／双方超时／中止不授予彩头。下一局编辑保留上轮结果；活动对局中不可修改，彩头摘要放在触控按钮下方。
- 不修改原同屏彩头设置、导入库或战绩。彩头只属于当前房间的临时协调状态，不新增长期文件／存储；好友、邀请码既有 GitHub 私有仓库边界保持。心跳和选彩头不访问 GitHub；过期约定在分享邀请开局前即拒绝，不消耗私库邀请码。
