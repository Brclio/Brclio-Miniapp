Brclio 悦创小程序用户隐私保护指引补充说明
文档更新日期：2026年10月22日

本说明补充微信平台展示的《Brclio 悦创小程序隐私保护指引》，说明当前原生小程序的实际功能、信息用途、存储与联系渠道。文档日期不代表微信后台已审核通过或本次指引已正式生效。

一、服务与自愿使用
服务提供者为莆田市荔城区黄家蓉宝电脑店。当前提供摄影浏览、ReadyGoDuel 双人挑战、计分扩展，以及 LingoTiles 词了个词学习。使用上述内容无需注册或登录。
「我的」提供可选的小程序独立账号，支持邮箱、账号、密码与邮箱验证码注册，邮箱或账号密码登录、邮箱验证码登录，以及微信直接登录注册；微信新账号可绑定邮箱与账号。账号功能需要联网，由你阅读说明并主动同意后使用。未登录或不使用账号仍可使用摄影、挑战和学习内容，访客进度先存本机；登录后自动同步白名单范围内的学习和挑战数据，每个账号的数据分别保存。

二、相册（仅写入）
在你主动点击「保存到相册」时，小程序调用微信相册写入接口，将本机生成的对决战报图片保存到手机相册。此功能不读取相册中的原有照片或视频。拒绝相关授权不影响摄影浏览和挑战。
你主动保存到手机相册的图片由你自行管理；清理小程序缓存或退出账号不会删除这些图片。

三、选中的文件
在你主动选择「从 .txt 导入自定义彩头」时，小程序调用微信聊天文件选择接口，只读取你选中的一个 TXT 文件，并以 UTF-8 文本按非空行导入彩头清单。文件导入链路只在本机处理和缓存，不上传原始文件或导入的彩头内容，不读取聊天记录或其他未选中的文件。
你可以不使用文件导入，继续使用默认彩头或手动设置彩头。

四、剪切板
在计分扩展中，你主动点击「原作与来源」后，小程序把固定的原作项目网址写入系统剪切板，以便复制、访问或分享。此功能不读取、不保存也不上传剪切板原有内容。
当前复制的网址为：https://github.com/AndersonHJB/ReadyGoDuel
微信平台在用户隐私信息类型中将剪切板写入接口与读取接口归入同一项，本小程序的实际行为仅为上述主动写入。

五、邮箱、独立账号与微信登录信息
当你自愿通过邮箱注册时，需要填写账号名、邮箱、账号密码和邮箱验证码。邮箱用于接收注册、登录或绑定邮箱验证码并验证邮箱归属；邮箱或账号名与密码用于密码登录，邮箱与对应验证码用于验证码登录。账号名同时用于资料展示。账号密码用于后续密码登录校验，邮箱验证码用于本次对应用途的验证；两者不写入小程序本机缓存，验证码不向前端接口返回。
当你主动选择微信登录时，小程序通过 wx.login 获取临时登录凭证，服务端向微信换取你在本小程序内的用户标识，首次建立独立账号，之后登录同一用户。微信标识经服务端派生为账号索引；微信会话密钥不存入仓库或返回小程序。本功能不申请微信昵称、头像或手机号，不自动关联其他 Brclio 产品的账号。微信登录服务会按微信规则处理登录请求。
账号请求由 pocket.bornforthis.cn 的本项目独立后端处理，不转交此前的跨产品中央账号服务。账号、邮箱、身份验证记录、登录会话摘要、验证码验证记录和安全限流记录保存在 BrclioData/Brclio-Miniapp-UserData 私有仓库，每位用户有独立目录；小程序应用业务云端数据仅使用 BrclioData/Brclio-Miniapp-Data 私有仓库。业务同步仅接受明确的声音、振动、挑战设置和最近20场计分战绩，以及学习进度、收藏、学习偏好和最近200条通关足迹。操作后先本机保存，再后台同步，网络失败时保留待同步记录，恢复网络重试。GitHub 访问凭据只在后端使用。
本机缓存当前用户的会话和必要账号展示资料以保持登录。退出会移除本机会话，并在联网成功时撤销该服务端会话；网络失败时立即结束本机登录，并在恢复网络后重试服务端撤销。退出不自动注销账号或删除本机挑战、学习记录。为限制验证码滥用与异常登录，服务端使用网络请求 IP 派生不可逆限流标记，不在账号仓库存储原始 IP。

六、挑战设置、彩头与对局记录
ReadyGoDuel 在微信本地缓存保存自定义标题、玩家名、等待时间、自定义彩头等设置，用于继续挑战、随机选取彩头和生成战报。
计分扩展在本机缓存保存赛制、振动偏好、玩家名，以及最近20场对局的时间、胜方、比分和反应成绩，用于展示历史战绩与继续使用。
登录后自动同步挑战的非敏感设置和计分记录。TXT 文件、ReadyGoDuel 自定义彩头与彩头查看密码仍只在本机使用，不上传。首次登录仅将已有访客进度领取到首个账号一次，之后按账号隔离，不把其他账号记录合并进来。此前共享账号缓存不读取或自动迁移。

七、学习偏好、记录与发音
词了个词在当前设备保存学习偏好、已学习词条、收藏、关卡成绩与通关足迹，用于继续学习、展示学习记录和主动导出通关记录。登录后自动同步学习进度、收藏和学习偏好，云端保留最近200条通关足迹；本机完整历史仍可导出。访客使用时不上传。云端恢复仅在安全页面切换点合并，不在进行中的对局内覆盖。
词库与现有插图通过 pocket.bornforthis.cn 按需获取。只有你主动点击发音或开启消除朗读时，服务端才将当前英文单词发送到有道词典发音接口 dict.youdao.com/dictvoice 取得音频。该请求不向有道转发账号认证请求头。播放发音不需要录音或麦克风权限，也不会采集你的声音。

八、窗口信息与未使用的权限
界面与画布读取窗口尺寸、安全区域和像素比，仅在本机用于排版与触控适配，不用作设备身份标识上报。
当前版本不调用微信头像昵称、手机号、位置、摄像头、麦克风、通讯录、蓝牙、微信运动、加速度、磁场、方向或陀螺仪接口。摄影内容为开发者提供的内置展示图片，没有从用户相册选择照片或视频、拍照上传的功能。
未来如新增相关功能，将按实际变更更新说明并在需要时取得相应授权，不以事先勾选未使用项目替代告知和授权。

九、外部服务与信息存储
原生小程序未接入第三方微信插件、广告 SDK 或访问行为分析 SDK。以下是实际外部服务关系，不等同于接入相应的客户端 SDK：
1. 微信提供小程序运行与微信登录服务，处理取得登录凭证和验证本小程序用户身份所需的信息。
2. Cloudflare 承载 pocket.bornforthis.cn 的资源分发、独立账号后端与安全防护。账号字段通过该后端完成处理；网络访问所需的请求信息也由基础设施按其服务规则处理，不宣称服务完全不处理网络信息。
3. GitHub 存储上述两个私有仓库内的账号、身份验证、安全记录及主动提交的应用偏好。仓库授权管理者可访问资料和历史版本。当前不将照片、挑战战绩或学习记录存入这两个仓库。
4. Gmail（Google）发送注册、登录和绑定邮箱验证码，处理收件邮箱、验证码邮件主题及正文。账号密码不包含在验证码邮件中；邮件提供方按其服务规则处理投递信息。
5. 有道仅接收你主动请求发音的当前英文单词并返回音频，不接收本服务账号密码或账号认证请求头。
当前邮件方案使用 Gmail，不要求额外使用 Resend；未来若变更实际提供方，会先更新相应说明并按需要取得同意。
独立网页 ReadyGoDuel 保留原作访问量统计脚本；该脚本不在原生小程序挑战中运行。

十、保存期限与清理
我们以实现已说明用途所必要的范围处理信息。不同数据具有不同的保存与清理方式，不适用一个统一的固定天数：
1. ReadyGoDuel 自定义标题、玩家名和自定义彩头本机缓存：最后保存后7天有效，到期后在下次进入该玩法读取缓存时清理。等待时间等其他偏好不适用这一期限。
2. 计分扩展：本机最多保留最近20场完整对局，可在挑战功能中清空本机历史。恢复前副本、其他偏好、学习记录与收藏等本机缓存没有统一自动到期时间，可以通过相应功能或微信清理小程序缓存处理。
3. 账号资料与自动同步的业务数据：在提供相应服务所需期间保存，当前没有统一的自动到期清理期限。登录会话没有固定到期时间，不因长期未使用或其他设备登录而退出；主动退出会撤销当前设备会话。清理小程序缓存后需重新登录；邮箱验证码10分钟有效，单条最多失败5次。验证码、会话与限流窗口到期后失效，不等于仓库记录和历史版本已经自动擦除。查阅、更正、删除账号资料或申请注销，请联系开发者并验证账号归属；处理方式与时限遵循微信平台主指引公示的承诺及适用要求。
4. Git 历史可能保留旧版本数据，删除请求需要结合实际保存位置处理；本说明不将退出登录、删除当前文件或清理本机缓存等同于已删除全部云端历史。旧共享账号不会自动迁移；如需处理此前的账号资料，可通过同一联系渠道核实。
5. 已主动保存到手机相册的战报由你自行管理。
