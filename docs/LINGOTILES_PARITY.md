以下功能均已代码接入；实体手机的触控、音频、文件、存储和布局仍应按右栏验收。自动测试与模拟器结果以最终验证记录为准，不用源码表格代替测试结果。

| 功能 | 保留或适配的行为 | 待实体手机验收 |
| --- | --- | --- |
| 经典主题 | 词汇花园、日常小事、城市漫游、心情调色盘、灵感工作室、探索远方，六关共 54 个精选词 | 断网选关、记忆、通关、重玩 |
| 分级闯关 | 小学至大学六阶段，按阶段和关次选择；保留词数和记忆强度递增 | 合法域名下真实加载、断网错误和重试 |
| 记忆准备 | 点击开始后才计时，完整展示本关英文、词性、含义；可提前开始消除 | 小屏长词与释义、倒计时切换 |
| 记忆时长 | 主题可选 30／60／90 秒；分级使用本关标准时长及延长选项 | 切换选项、暂停后恢复 |

| 暂停与计时 | 记忆和消除分段记录；暂停、说明弹层与合成展示不计入相应时间；切后台后按实际时间结算 | 后台切换、系统中断和时间变化 |

## 网络、离线与数据边界

1. **代码与资源分开。** 原生规则、界面和经典 54 词内置于小程序；10 万词库分片、查词索引、现有插图索引及图片随独立网页构建。分级选关、单词本页、搜索与当前词义插图根据选择按需读取，不在每次进入时下载全部词库和全部图片。搜索可能读取多个词库分片，并显示进度。
2. **资源地址固定。** 原生资源位于 `https://pocket.bornforthis.cn/projects/lingotiles/vocabulary/…` 与 `https://pocket.bornforthis.cn/projects/lingotiles/images/…`。微信生产环境需将 `pocket.bornforthis.cn` 配置为 **request 和 downloadFile 合法域名**；当前界面不需要 web-view 业务域名。
3. **离线范围明确。** 获取小程序代码包后，经典六关及仅含内置经典词的收藏页不依赖词库网络请求；混合分级词的收藏页需联网，失败可重试。插图和朗读仍需联网。分级词库依赖按需加载，不承诺首次打开时离线可读全部 10 万词。浏览器缓存或当前会话缓存不等同于持久离线下载能力。
4. **语音只发送当前单词。** 原生请求 `/api/lingotiles/pronounce?word=…`，由同域服务端固定转发至 `https://dict.youdao.com/dictvoice`，不接受任意远程目标。只有主动点击发音或开启消除朗读后才发起语音请求，不采集麦克风或录音。网页发音使用浏览器能力，是否可用取决于设备和浏览器。
5. **学习数据仅保存在本机。** 收藏、已学、进度、最佳成绩、逐次足迹、学习偏好和待配图词单不上传账号服务，不进入现有 Brclio 账号的挑战备份。登录不会带来学习跨设备同步。清除小程序缓存、浏览器数据或卸载可能删除这些记录；可主动导出足迹保留副本。
6. **现有插图按索引读取。** 保留的 1,083 个已配图义项和 98,917 个待配图义项均来自固定来源；本轮不把待配图词条描述成已完成，不在客户端调用生成服务，不新增图片生成费用。

## 验收顺序

先完成构建、来源和资源完整性检查，再运行规则与页面测试，随后检查手机尺寸的网页及微信模拟器，最后在 iOS／Android 实机验证联网、发音、计时、存储、文件分享和布局。Pages 部署、微信开发包上传、审核与正式发布分别记录，不能由前一阶段推断后一阶段成功。
