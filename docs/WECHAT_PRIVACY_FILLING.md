# 微信用户隐私保护指引填写表

核查日期：2026-10-25。适用范围：当前仓库中的原生微信小程序，含可选的小程序独立账号、邮箱验证码与微信登录；访客记录保存在本机；登录后自动同步白名单内的挑战与学习记录。以下是待填报内容，不表示微信后台已保存、审核通过或正式发布。

自定义信息的名称与用途应分别填写；如果后台只允许一条自定义，可将上述各组自定义信息合并填写，完整处理说明见补充 TXT。表中自定义名称是处理信息的描述，不代表后台已有同名菜单；以实际后台可选类型和自定义入口填写，不把独立账号名或微信登录标识选成「微信昵称、头像」。业务同步以 `/sync` 的字段白名单为准，头像独立通过 `/avatar` 设置，不进入业务同步文档。

剪切板说明：虽然当前代码只调用 wx.setClipboardData 写入固定来源链接，没有调用 wx.getClipboardData 读取内容，但微信官方信息类型映射将两者都归为「读取你的剪切板」，因此保留该项并按真实用途填写。

## 2. 当前版本应删除或不勾选的项目

| 项目 | 当前行为与操作 |

| 磁场传感器 | 删除；没有指南针或磁场采集功能。 |

地址、身份证号、订单、蓝牙、通讯录、定位、微信运动等没有实际使用的项目，不为预留未来功能而添加。界面当前会读取窗口尺寸、安全区域、像素比用于本机排版，已在补充文档中单独说明；不要据此写成上传设备标识、设备型号或定位。

## 4. 提交前要区分的状态

- 本地声明已按头像功能更新；本轮后台自动读取持续超时，尚未保存后台隐私指引或提交、撤回微信审核。不得将本地文案更新视为后台已生效。
- 「账号设置／服务内容声明」修改现网版本指引；「版本管理／提交代码审核／信息填写」修改提审版本指引，两者独立。要纠正本次提审，需确认改的是对应提审版本。
- 当前没有自行注册隐私授权监听，调用已声明的隐私接口时可由微信官方隐私授权弹窗处理；不要仅因没有自定义弹窗就认定无需授权。用户拒绝后不能绕过授权继续处理。
- TXT 导入、相册保存、复制来源链接的实体设备授权与拒绝流程，需要在后台声明生效后实际核验；独立账号还需核验主动同意、拒绝后继续访客使用、邮箱送达、微信登录和退出流程。本地文案检查不能证明后台已生效。
- 旧共享账号不自动迁移，新账号固定使用 BrclioData/Brclio-Miniapp-UserData；应用业务数据固定使用 BrclioData/Brclio-Miniapp-Data。两个仓库均为私有，每位用户独立目录；Git 历史保留边界见补充 TXT。
